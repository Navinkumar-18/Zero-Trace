# Agent Guidelines

## Git & Branching Rules

- Work on the branch that is currently checked out; do not create branches unless I ask. Commit small and often (one logical change per commit, conventional messages) and only after flutter analyze, flutter test and the cargo checks have passed. Start every task with a clean git status; if it is not clean, stop and tell me.
- Never push, force, reset --hard, checkout ., clean, rebase, or amend. I push and roll back myself.
- Before engine, guard or signing changes, remind me to tag a checkpoint.
